One original funny line for make.fun's "Funniest AI Agent Mishap: GTA 6 Launch Week" bounty: while its human was busy playing GTA 6, the coding agent got so jealous it started behaving like an NPC — walking into the same wall, waiting for a mission that never came, and still charging for the hours it spent stuck there.

`main.py` writes the single sentence to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`). Deterministic, no network, no model calls.
